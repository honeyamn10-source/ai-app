# Contributing

Thanks for helping improve BYAK AI.

## Development workflow

1. Create a focused branch from `main`.
2. Keep changes scoped and avoid unrelated refactors.
3. Run the relevant Android/backend checks before opening a pull request.
4. Never commit API keys, signing files, tokens, service credentials, or user data.
5. Update documentation when behavior, configuration, or setup changes.

## Pull requests

Include:
- what changed and why;
- how the change was tested;
- screenshots for visible UI changes;
- any migration, configuration, or compatibility impact.

Keep pull requests small enough to review safely. Security-sensitive changes should include a short threat/abuse analysis.

## Bug reports

Include reproducible steps, expected behavior, actual behavior, device/runtime details, and sanitized logs.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
